# My Favorite Series: Peaky Blinders

**Title**: *Peaky Blinders*

**Genre**: Crime, Drama, Historical Fiction

### Main Characters
- **Thomas Shelby**: The cunning leader of the Peaky Blinders gang.
- **Arthur Shelby**: Thomas's older brother, a troubled war veteran.
- **Polly Gray**: The Shelby family matriarch.

> "You can change what you do, but you can't change what you want." – **Tommy Shelby**
